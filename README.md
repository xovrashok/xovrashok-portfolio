# ⚡ Personal Developer Portfolio

A dynamic, high-performance developer portfolio built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**. The application showcases professional commercial experience, tech stack skills, interactive project showcases with filtering, and educational background with a sleek dark slate theme.

## ✨ Features

- **Interactive Project Showcase:** Filter projects dynamically by tech categories with custom browser-style preview cards.
- **Ambient Motion Background:** Built with custom Tailwind CSS `@keyframes` animations providing a subtle floating background gradient.
- **Glassmorphic Navigation:** Fixed header and compact footer integrated with `backdrop-blur-md` for a modern UI feel.
- **Responsive Layout:** Clean CSS Grid and Flexbox design optimized for seamless viewing across all mobile, tablet, and desktop viewports.
- **Structured Data:** Built using modular component structure with typed interfaces for work experience, tech stack, and education history.
- **CV Download & Quick Actions:** Integrated direct actions for downloading CV and quick contact options.

---

## 🛠️ Tech Stack & Libraries

- **Core Framework:** `React 18` and `TypeScript`
- **Build Tool:** `Vite`
- **Styling:** `Tailwind CSS v4`
- **Icons:** `lucide-react`
